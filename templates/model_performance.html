Deep Neural Network (DNN) AI Core Specification

🧩 Deep Neural Network Layer-by-Layer Architecture

Input Layer
10 Normalized Academic Features (StandardScaler normalized, mean=0, variance=1)
Input Shape: (None, 10)
↓
Hidden Layer 1: Dense(64) + BatchNormalization + Dropout(0.3)
Activation: ReLU • L2 Regularization (0.001) • Prevents internal covariate shift
Output: (None, 64)
↓
Hidden Layer 2: Dense(32) + Dropout(0.2)
Activation: ReLU • L2 Regularization (0.001) • Refines latent academic representations
Output: (None, 32)
↓
Hidden Layer 3: Dense(16)
Activation: ReLU • Compresses feature abstractions into risk classification logits
Output: (None, 16)
↓
Output Layer: Dense(3, activation='softmax')
Computes normalized probability distribution: [P(Low Risk), P(Med Risk), P(High Risk)]
Output: (None, 3)
